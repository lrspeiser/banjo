# Stable advice, explicit help and carried lamp recovery

October 3, 2026. Based on main `a8321dc1`. The full construction goal remains
active. This slice repairs the owner's observed guide flicker, excessive advice
refreshing, vague fourth placement step and carried lamp becoming a block.

## Changes

- The shared World/Workshop renderer retains the same tip node during an
  unchanged next-action refresh. A delayed or temporary provider response
  cannot collapse a valid tip. Superseded replies cannot resurrect dismissed
  advice. A changed task clears its old explanation immediately.
- **Ask AI · F1** explicitly requests advice. Unchanged five-second card
  refreshes make no assist request. Ordinary new exploration tasks read advice
  status without launching a model. Automatic construction explanations are
  attempted once per selected item/phase in the page, with bounded history.
  Existing private dismissal, worker limits and 20-second provider cooldown
  remain. A manual request can use cached advice or ask while Quiet is enabled;
  it preserves Quiet/dismiss preferences for later automatic events. Pending
  manual status polls do not launch another provider call.
- Step 4 is **View components and use**, with a direct World inspection button.
  It shows the light's actual native on/off reading, power source and declared
  automatic/manual mode. The starter light explicitly says it switches on at
  night and off in daylight. Opening inspection saves a private acknowledgement
  with the same revision/retry receipts and a native reach/placement check.
  The completed row means the player opened inspection; it is not a settling,
  strength, access or operation certificate and earns no skill.
- New starts retain the camp light's exact editable recipe. Older starts
  recover the mine-lamp source only after every compiled component material,
  dimension and local transform matches. Renaming preserves this match;
  changing a dimension fails. The Lab opens the iron foot, iron bracket and
  glass globe rather than an invented 100 mm block. Unknown compounds with no
  editable source report that limitation and keep the physical item unchanged.
  A previous browser draft with a different source remains unapplied.
- Verification exposed an existing random-map failure: graph reachability
  could succeed while the smelter's clear, dry footprint beside its heaps was
  refused. World generation now includes composition in its existing bounded
  six-attempt reseeding loop. Failed candidates are not saved. Native admission
  still runs before publishing a world; no fit/clearance rule is relaxed.
