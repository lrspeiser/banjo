## Reported failure and repair

The 10 m overview camera admitted the whole trajectory but made the actual
centimetre-scale sphere effectively subpixel on a phone. Position labels moved
while the object was invisible. Primary actions were below a long information
panel. Fast accepted calculations also advanced visible endpoints immediately.

The rigid control now starts with a close-up following the real-sized sphere.
Full drop remains available for the whole path. The infinite native ground is
represented by a larger finite drawing patch; the sphere geometry, ground height
and physics remain unchanged. Drop, Stop, Set up and Replay are beside the scene,
with 44 px touch targets and explicit zoom buttons.

Replay retains measured intermediate native poses at up to 240 render samples
per physical second, preserving the latest delivered state separately. It uses
physical elapsed time, pauses at the last delivered state, and never extrapolates
or adds a simulated pose. A two-second experiment retains at most 481 sampled
frames plus its last state. Exact contact inspection remains independently
retained. Saved continuation does not acquire render-history dependencies.

The hosted source badge now checks the image's source, implementation and native
binary receipt together. An old local checkpoint cannot invalidate a matching
image or conceal an invalid image receipt. Tests reject changed receipt fields.
Identity verification is not physical qualification.
