## Implemented behavior

Build combines the recipe shelf and selected Lab preview. A fresh Lab is empty;
Make my first tool selects the supported Personal field pick without spending.
Recipe thumbnails and Select & edit open a draft. Owned hands/bag, saved and
library sources use the existing authenticated selection paths. Chat edits use
the bounded Workshop tools and update the actual candidate preview; per-source
drafts survive reload. Save design and Review Make are visible beside the
selected draft. Save retains an authoring record; paid Make retains the native
review, funding, work, collection and placement boundaries.

Inventory/Market and Progress/Skills/Goals remain combined hubs. Material links
give context while keeping the supported recipe catalog reachable. An unrelated
or unsupported material no longer produces an empty filtered screen. Advanced
building blocks and designs needing changes are labeled disclosures.

Guide chat offers a bounded server-derived source/action catalog. Its tools can
open a reversible Lab selection or offer navigation; they cannot manufacture,
buy, equip, place, award skills or change native state. Guide history is retained
in private browser session storage across screens. Failed turns re-enable input.
Design edits retain their existing separate candidate tools and atomic failure
behavior. Optional `BANJO_GUIDANCE_MODEL` selects the guide model independently
of Workshop; this checkpoint does not establish a provider latency guarantee.

World's next-step card stays hidden until explicit help or active placement.
World navigation clears stale Lab recipe/material URLs. Returning to Build and
selecting the previous source restores its browser draft. A rover has one compact
selection/control view: thumbnail, native status, energy and actual cargo,
Talk to rover, and one Start/Stop/Recover action. Talk targets the same World
chat audience selector and existing native rover endpoint. Native execution,
power, recovery and permission guards remain authoritative.
