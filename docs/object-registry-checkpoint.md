## Implementation and limits

- [Registry](../scripts/object_registry.py): immutable canonical SHA256 definitions, separate persistent world/instance/matter/interface IDs, local reference frames, installed unit-bearing material/law recipes, exact native ownership and bounded JSON checkpoints. Floating values use explicit IEEE binary64 hex tags, retaining every bit (including negative zero) across browser JSON parsing/stringifying. Actual Node and HTTP round trips are regression tested; large integer metadata outside the browser exact range is refused. Primitive volumes and full geometric inertia tensors are independently calculated, including gaps and parallel-axis terms. The existing solver still uses its existing cell inertia model; full tensor authoring does not implement new rotational dynamics.
- [World](../scripts/gpu_coupled_world.py): snapshots include registry summaries; accepted ownership and GPU/host continuation roll back together. Restore builds privately, checks checksum, installed source/definition/version, complete maps, finite geometry/history, clocks, owners, prescribed boundaries and stored-energy consistency before publication. Geometry/law edits are rejected. This is a compiler for the current factory scenes, not arbitrary imported meshes or a general LLM authoring endpoint.
- Exact native serialization retains all constitutive state and cumulative physical accounts. Private derived caches are rebuilt. Past render frames and full failed candidate witnesses stay in the original journal, not the scene file. A saved stopped scene stays stopped. A checkpoint is bounded to 2 MB and tied to the exact installed physics fingerprint; it is not migration across physics revisions.
- An unattached sphere needs no material-rest reference. Before coupled solving, only its numerical translation origin/increment columns are recentered around its **unchanged physical position**. Resolving micrometre contact after subtracting approximately ten metres made finite differences unreliable. The repair changes no physical pose, velocity, mass, inertia, interface/history, gravity, law, damping or tolerance. Connected cells retain their original material-rest references. Accepted accounts record the map; native rollback and restart retain the numerical basis exactly.
- This implements only existing rigid primitive and connected rigid-cell graph instances. Sleeping, articulated/reduced solids, detailed sphere and fragment transfers, adaptive refinement, flowing matter, thermal/reaction fields and generic creator recipes remain unimplemented. Naming eight families does not supply eight solvers. Oak remains isotropic without grain; iron connector plasticity is not continuum J2 denting.
